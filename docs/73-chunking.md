## 1. 결론과 판정 구간

- 질문 123개(#131 golden 그대로), 정답은 조 단위다. 주 지표는 hybrid recall@5이고 측정 전에 정했다.
- 고르는 규칙: `article` 대비 hybrid recall@5 차이의 95% CI 하한이 0보다 큰 후보 중 평균이 가장 큰 것. 같으면 청크 수가 적은 쪽. 그런 후보가 없으면 `article`을 유지한다.
- 신뢰구간은 paired bootstrap 10,000회, p는 paired permutation 10,000회(seed 0)다. p는 10,000회 검정이라 0.0001이 하한이다.
- 후보 4개를 같은 `article` 하나와 비교하고 다중 비교 보정은 하지 않았다.
- 구간: 하한 > 0 → 차이 있음 / 0을 포함하고 폭의 절반 ≤ 0.05 → 차이 없음 / 0을 포함하고 폭의 절반 > 0.05 → 판정 불가 / 상한 < 0 → 낮다. 네 후보 모두 낮다이면 `모든 후보가 낮다`.
